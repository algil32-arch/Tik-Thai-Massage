# Thai Tik Massage — Site Ver 4.0

Sito statico multipagina per Thai Tik Massage, con backend PHP/MySQL predisposto per l'hosting Aruba.

## Run locally

Open `index.html` in a browser, or run:

```bash
cd path/to/Tik-Thai-Massage
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Versione 4.0

Consulta [RELEASE_NOTES_V4.md](RELEASE_NOTES_V4.md) per le modifiche di questa versione.

Il selettore lingue usa il widget esterno GTranslate per italiano, inglese, thailandese e spagnolo. Prima della pubblicazione verifica la traduzione sul dominio Aruba e aggiorna l'informativa privacy per il servizio esterno. Il flusso PHP/MySQL richiede configurazione e collaudo sull'hosting reale.
