# Tik-Thai-Massage

Simple static website for Tik Thai Massage.

## Run locally

Open `/home/runner/work/Tik-Thai-Massage/Tik-Thai-Massage/index.html` in a browser, or run:

```bash
cd /home/runner/work/Tik-Thai-Massage/Tik-Thai-Massage
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
